# CodeAlpha Hangman Game

## 📌 Project Description

This project is a simple text-based Hangman Game developed using Python as part of my CodeAlpha Python Programming Internship.

The player has to guess the hidden word one letter at a time. The game provides a limited number of incorrect guesses. The player wins by guessing the word correctly before the maximum number of incorrect guesses is reached.

## 🎯 Objectives

- To develop a simple command-line game using Python.
- To practice Python programming concepts.
- To use loops, conditions, functions, strings, and user input.
- To improve problem-solving and logical thinking skills.

## 🛠️ Technologies Used

- Python
- Visual Studio Code
- Command Line / Terminal

## 🎮 How to Play

1. Run the Python program.
2. The program selects a hidden word.
3. Guess one letter at a time.
4. Correct guesses reveal the letters in the word.
5. Incorrect guesses reduce the number of available attempts.
6. Guess the complete word before the maximum incorrect guesses are reached to win.
